## Хэсэг А: Category-Partition арга

### 1. Даалгавар А1: Сонголт ба төлөөлөх утгууд

Шилжүүлгийн функцийн (`POST /transfer`) параметрүүдийн сонголт болон төлөөлөх утгууд:

| Параметр | Сонголт  | Төлөөлөх утгууд | Тайлбар / Утга |
| :--- | :--- | :--- | :--- |
| **from** | `Valid` | `ValidAccount` | Хүчинтэй, идэвхтэй илгээгч данс |
| | `Frozen` | `FrozenAccount` | Царцаагдсан данс [ERROR] |
| | `Missing` | `Null / NonExistent` | Байхгүй эсвэл хоосон ID [ERROR] |
| **to** | `Valid` | `ValidAccount` | Хүчинтэй хүлээн авагч данс |
| | `Missing` | `Null / NonExistent` | Байхгүй хүлээн авагч данс [ERROR] |
| | `SameAsFrom` | `SameID` | Илгээгчтэй ижил ID-тай данс [ERROR] |
| **amount** | `Normal` | `50` | Хэвийн, боломжит дүн (> 0) |
| | `Zero` | `0` | Тэг утгатай дүн [ERROR] |
| | `OverBalance` | `15000` | Дансны үлдэгдлээс их дүн [ERROR] |
| | `OverLimit` | `2000` | Өдрийн лимитээс хэтэрсэн дүн [ERROR] |
| **currency** | `Same` | `MNT` | Илгээгч дансны валюттай ижил |
| | `Different` | `USD` | Ханшийн хөрвүүлэлт хийгдэх өөр валют |
| **Далд орчин** | `DailyLimitStatus` | `UnderLimit`, `Exceeded` | Өдрийн лимит хэр дүүрсэн байдал [SINGLE] |

### 2. Даалгавар А2: Хязгаарлалт ба Тооцоолол

* **Тэмдэглэгээний үндэслэл:**
  * `[ERROR]`: Алдаа үүсгэх гол нөхцөдүүд (жишээ нь: байхгүй данс, царцаасан данс, дүнгээс хэтэрсэн байдал).
  * `[SINGLE]`: Орчны далд төлөв болон нэг удаа шалгахад хангалттай параметрүүд.
  * `[IF/property]`: Данс байхгүй эсвэл буруу үед amount болон бусад хамааралтай шалгалтыг хязгаарлах нөхцөл.

* **Бүрэн олонлог ба хязгаарлалтын тооцоолол ($N \rightarrow M$):**
  * Параметрүүдийн сонголтын тоо: `from` (3) $\times$ `to` (3) $\times$ `amount` (4) $\times$ `currency` (2) = **72 боломжит бүрэн олонлог ($N = 72$)**.
  * Хязгаарлалтууд (утга давхцахгүй байх, байхгүй дансанд amount шаардлагагүй гэх мэт) болон алдааны боломжит нэгтгэлүүдийг хассанаар бодит тест кейсийн тоо цөөрсөн.
  * Үр дүн: **$72 \rightarrow 18$** (Хязгаарлалт хийсний дараах бодит тестүүдийн тоо).

### 3. Даалгавар А3: Спецификацийн хүснэгт ба Алдааны давуу эрэмбэ

**Алдааны давуу эрэмбэ (Priority):** 
`from` (Байхгүй/Царцаагдсан) $\rightarrow$ `to` (Байхгүй/Ижил) $\rightarrow$ `amount` (Тэг/Лимит/Үлдэгдэл)
Хэрэв нэг хүсэлтэд олон алдаа зэрэг байвал дээрх эрэмбээр эхний алдааны код буцна.

| № | from | to | amount | currency | Хүлээгдэх үр дүн (Oracle) | Тайлбар / Төрөл |
|---|---|---|---|---|---|---|
| **1** | Valid | Valid | Normal | Same | `201 OK` | Happy Path |
| **2** | Valid | Valid | Normal | Different | `201 OK` | Валютын хөрвүүлэлттэй |
| **3** | Frozen | Valid | Normal | Same | `200 ERROR_FROZEN` | Царцаагдсан данс [ERROR] |
| **4** | Missing | Valid | Normal | Same | `200 ERROR_NO_FROM` | Илгээгч байхгүй [ERROR] |
| **5** | Valid | Missing | Normal | Same | `200 ERROR_NO_TO` | Хүлээн авагч байхгүй [ERROR] |
| **6** | Valid | SameAsFrom | Normal | Same | `200 ERROR_SAME_ACCOUNT` | Ижил данс хооронд [ERROR] |
| **7** | Valid | Valid | Zero | Same | `200 ERROR_BAD_AMOUNT` | Tэг дүн [ERROR] |
| **8** | Valid | Valid | OverBalance | Same | `200 ERROR_INSUFFICIENT` | Дансны үлдэгдлээс их [ERROR] |
| **9** | Valid | Valid | OverLimit | Same | `200 ERROR_LIMIT` | Өдрийн лимит хэтэрсэн [ERROR] |
| **10** | Missing | Missing | Zero | Same | `200 ERROR_NO_FROM` | Давхар алдаа (Эрэмбээр эхэлж шалгагдана) [SINGLE] |

## Хэсэг Б: PICT хэрэгсэл

### 1. Даалгавар В1: Browser жишээний шинжилгээ
* **2-way мөрийн тоо:** `results/browser-2way.txt` файлын мөрийн тоо **10** гарсан. PICT нь greedy алгоритм ашигладаг тул зарим үед хамгийн цөөн мөрийг шууд олохгүйгээр өгөгдсөн хослолуудыг бүрэн хамрах зорилгоор ойролцоо оновчтой тоог гаргадаг.
* **3-way мөрийн тоо:** `results/browser-3way.txt` файлын мөрийн тоо илүү олон гарсан бөгөөд бүрэн олонлогийн хэмжээтэй харьцуулахад хамаагүй цөөн буюу **20** хослолын далд боломжийг оновчтой багасгасан байна.
