## Хэсэг А: Category-Partition арга

### 1. Даалгавар А1: Сонголт ба төлөөлөх утгууд

Шилжүүлгийн функцийн (`POST /transfer`) параметрүүдийн сонголт болон төлөөлөх утгууд:

| Параметр | Сонголт (Category) | Төлөөлөх утгууд (Choices) | Тайлбар / Утга |
| :--- | :--- | :--- | :--- |
| **from** | `Valid` | `ValidAccount` | Хүчинтэй, идэвхтэй илгээгч данс |
| | `Frozen` | `FrozenAccount` | Царцаагдсан данс [ERROR] |
| | `Missing` | `Null / NonExistent` | Байхгүй эсвэл хоосон ID [ERROR] |
| **to** | `Valid` | `ValidAccount` | Хүчинтэй хүлээн авагч данс |
| | `Missing` | `Null / NonExistent` | Байхгүй хүлээн авагч данс [ERROR] |
| | `SameAsFrom` | `SameID` | Илгээгчтэй ижил ID-тай данс [ERROR] |
| **amount** | `Normal` | `50` | Хэвийн, боломжит дүн (> 0) |
| | `Zero` | `0` | Тэг утгатай дүн [ERROR] |
| | `OverBalance` | `15000` | Дансны үлдэгдлээс их дүн [ERROR] |
| | `OverLimit` | `2000` | Өдрийн лимитээс хэтэрсэн дүн [ERROR] |
| **currency** | `Same` | `MNT` | Илгээгч дансны валюттай ижил |
| | `Different` | `USD` | Ханшийн хөрвүүлэлт хийгдэх өөр валют |
| **Далд орчин** | `DailyLimitStatus` | `UnderLimit`, `Exceeded` | Өдрийн лимит хэр дүүрсэн байдал [SINGLE] |
